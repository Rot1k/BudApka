# Звіт виконаної роботи після db13354

Базовий коміт — `db13354` від 22 листопада 2026 року. Цей звіт описує зміни робочої гілки після нього, станом на 24 листопада 2026 року.

| Напрям | Що зроблено |
| --- | --- |
| Android і форми | Відкладено форматування номера до завершення обробки Android-введення. Вибір категорій і симптомів оновлює потрібні елементи на місці. Після вибору список категорій згортається до рядка з іконкою та позначкою. Перевірки прокручують форму до помилки. |
| Чернетка й адреса | Додано продовження, видалення та заміну чернетки з підтвердженням. Геолокацію перенесено вгору, результати пошуку вулиці розміщено біля кнопки пошуку. Підказки для залежних полів адреси мають текстовий вигляд. Геолокація зіставляє населений пункт із областю в локальному довіднику та заповнює адресу при однозначному збігу. |
| Профіль майстра | Для активації потрібні ім’я й телефон. Заповнені контактні дані беруться зі спільного профілю. Для активного майстра налаштування доступні вгорі профілю. |
| Пропозиції та замовлення | Заявка отримує одну позначену демопропозицію. Список відповідей показує найновіші першими. Майстер може повідомити про виконання, а клієнт — підтвердити завершення. Середня оцінка враховує збережені оцінки, лічильник робіт — усі завершені замовлення. Показники видно у профілі та на екрані вибору майстра. |
| Послуги та запрошення | Майстер може публікувати, редагувати й знімати окремі картки. Автозаповнення створює картки для відсутніх категорій профілю із зоною роботи й порожнім описом. Клієнт бачить каталог і рекомендації за категорією та адресою заявки. Майстер може прийняти або відхилити запрошення. У картках немає поля ціни, а бюджет клієнта й ціна у відгуку майстра необов’язкові. |
| Debug і збірка | Додано кнопку заповнення тестовими даними з 17 заявками у шести статусах, профілями, оцінками, чатами й запрошенням. Повторний виклик не дублює записи. У Windows файли збірки пишуться під `%LOCALAPPDATA%\BudApka\build` окремо для кожної робочої копії. |

## Перевірка

- Android Debug збирався та запускався на фізичному телефоні. Перший і повторний збір у новому каталозі пройшли без помилок. Windows Debug також зібрався з попередженнями `CsWinRT1032`.
- Окремі перевірки моделі охопили зіставлення адрес, статистику, картки послуг, запрошення, повторне заповнення тестових даних і відсутність цієї функції в Release.
- Результати проходження інтерфейсу та відкриті проблеми описано у [звіті UX-аудиту](Звіт_аудиту_UI_UX.md).

Дані прототипу живуть у межах сесії. Сповіщення й чат працюють локально. Механізм вирішення спорів і строк підтвердження виконання не реалізовані.
